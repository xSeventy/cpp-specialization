Solutions to programming assignments from the **Modern C++ Development** specialization.

This repository contains my solutions and notes from the following courses:

- **C++ Development Fundamentals: White Belt**

- **C++ Development Fundamentals: Red Belt**

## Courses

### White Belt

[`White_Belt`](./White_Belt)

C++ fundamentals, functions, standard containers, classes, file handling, exceptions, and basic algorithms.

### Yellow Belt

[`Yellow_Belt`](./Yellow_Belt)

Templates, inheritance, iterators, STL algorithms, program decomposition, and unit testing.

### Red Belt

[`Red_Belt`](./Red_Belt)

Advanced templates, memory management, optimization, profiling, multithreading, and performance-oriented programming.

## Repository Structure

```text 
cpp-specialization/

│   ├── Week_1/
```

Each programming assignment is stored in a separate directory:

```text 
Task_Name/
├── README.md
└── main.cpp
```

The task description is stored in `README.md`, while the corresponding solution is stored in `main.cpp`.
