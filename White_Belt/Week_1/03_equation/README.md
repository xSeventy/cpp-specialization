# Задание по программированию «Уравенине»


## Description

На вход вашей программы в стандартном потоке ввода подаются действительные коэффициенты A, B и Cуравнения Ax² + Bx + C = 0. Выведите все его различные действительные корни в поток вывода в любом порядке, при этом разделяя корни пробелами. Гарантируется, что хотя бы один из коэффициентов уравнения не равен нулю.


## Input

2 5 2 
2 4 2
2 1 2
0 4 10

## Output

-0.5 -2
-1

-2.5
